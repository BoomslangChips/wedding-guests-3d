# Third-party material

## MakeHuman base mesh and targets (CC0 1.0)

`3d/body.json` is derived from data files of the MakeHuman project (the base mesh, its default skeleton and skin
weights, and a small number of shape targets), converted into one compact file. MakeHuman's assets are released under
the Creative Commons CC0 1.0 Universal public domain dedication:

- MakeHuman: http://www.makehumancommunity.org/
- CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

No MakeHuman program code is included.

## Fonts

The demo page loads Pinyon Script, Playfair Display and Plus Jakarta Sans from Google Fonts. They are licensed under
the SIL Open Font License 1.1 and are not part of this repository.
